# paramap-icons

Windrosen-Symbole für Gleitschirm-Startplätze, erzeugt von paramap.

Dateiname `rose-XXXXXXXX.png`: 8 Stellen für N, NO, O, SO, S, SW, W, NW –
`0` = nicht startbar, `1` = möglich (hellgrün), `2` = gut (dunkelgrün).
`rose-unknown.png` = Richtung unbekannt.

Ausgeliefert über GitHub Pages: `https://prombi.github.io/paramap-icons/rose-00121100.png`
